# 2.2.0 界面重设计验收

本轮沿用 2.1.1 的真实内存整理实现；窗口检查使用独立预览的模拟 API，不为视觉验收执行真实整理，不修改用户的自动清理配置。

## 检查内容

- 核心整理、失败、取消、并发、自动策略与停靠状态原有测试；新增作者链接的准确路由、未知键、不安全协议和凭据 URL 拒绝。
- 三个作者链接按钮提供不同矢量路径、文字、辅助名称与提示；通过注入打开器核对准确地址，不打开额外浏览器窗口。
- 原作者署名、640×820 默认窗口、440×560 最小窗口、固定作者区和三个入口的可见性。
- 浅/深色文本颜色与基本色对对比度，设置大标题实际前景色、分段导航选中态、原生标题栏属性应用。
- 主体滚动、10 DIP 主题滚动条、窄窗口、四个设置分区、历史及 100%～200% 离屏渲染倍率。
- 底部岛原有尺寸、点击并发保护、三阶段、两秒成果、呼吸变色、收起与减少动画解除时钟；键盘焦点仍在设置弹出层。
- 原生更新通过旧进程正常退出、版本和程序哈希检查验收；不重新运行安装向导。公开附件必须核对长度和 SHA-256。
