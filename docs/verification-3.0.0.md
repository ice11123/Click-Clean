# 3.0.0 验证与边界

日期：2026-10-14。版本3.0.0，Windows 11 x64本机；测试使用独立输出目录，不覆盖用户正式安装或配置。

## 已完成

- 核心64组模拟测试：7种高级组合、调用顺序与返回码、取消、重复执行、无压力和未知压力跳过、后台闲置基线、前台保护、PID重用、执行前竞态、预算、冷却与快速回涨避让、语言与旧配置迁移。
- 界面180项检查：简体中文/English切换及持久化、首次语言选择、浅深色页面、弹出层、键盘与减少动画、整理岛过程及两秒结果、重复点击、失败与无实际处理对象、手动更新入口。侧栏连续往返不再恢复另一页导航按钮焦点，悬停和选择共用圆角，键盘焦点不再使用常驻黑框。
- 更新25项检查：真实Velopack本地发布源发现与下载、同版/降级、损坏包拒绝；实际UpdateService的离线、超时、取消、重试、就绪缓存再校验、仅显式应用；跨主版本只提示安装迁移，不下载/应用系统组件；组件缺失不阻断日常优化。
- 界面截图倍率100%～200%及最小窗口可达性。倍率为离屏渲染，不冒充所有真实显示器DPI验证。
- x86包保持独立数据与更新通道隔离，不提供高级提权组件。仅作为Windows 11 x64上的WOW64试验版本。

## 受控原生实验

只对本次创建并持有精确句柄的128MiB测试子进程调用`EmptyWorkingSet`，未裁剪用户其他应用。10对随机交替、同样预热的测试，测量裁剪后首次逐页访问：

| 条件 | 平均首次访问耗时 | 平均总缺页 |
| --- | ---: | ---: |
| 不裁剪 | 0.381 ms | 0.1 |
| 裁剪暖页后 | 38.955 ms | 32779.1 |

这是暖页被移出工作集后的恢复代价，不是全机提速实验。总缺页包含软缺页，不能据此宣称发生同等次数磁盘读取。实验支持默认避开活跃工作集的设计，不能证明后台闲置启发式对所有任务有净收益。

当时Windows报告低内存=false、充裕内存=true，日常策略返回空命令。未为实测制造全机低内存，未在用户电脑执行全系统三步。

## 发布门禁与未覆盖项

正式安装包必须使用固定提交构建的x64 Native AOT系统组件；构建脚本拒绝托管回退，核验PE、组件来源提交及SHA-256，执行协议/ACL纯逻辑自测。`privileged.yml`在隔离Windows runner部署到Program Files后执行双向认证探针，只发退出命令，不发整理指令；认证结果随CI产物保留。CI构建及认证不通过，不发布安装包。

本轮未在用户正式安装上做覆盖安装、卸载、旧任务迁移或全系统整理，也未完成标准账户跨UAC真人授权验收。CI管理员会话的IPC探针不能代替真实UAC交互测试。缺少正式代码签名证书，发行包仍未签名。

后台整理本质仍是有界工作集裁剪，可能增加目标应用恢复时的缺页；不解决其他应用内存泄漏。当前没有游戏帧时间、应用任务耗时的多场景A/B证据，不宣称普遍提速或固定释放量。默认策略的验收是减少无收益的全系统干预、处理范围真实受限、失败与跳过如实反馈，而不是把数字变好看。
