## 安装修复

修复3.0.2安装程序报“安装账户标识无效”并中断的问题。原因是安装脚本动态COM调用没有回写WMI的输出参数，并不是用户账户损坏。卸载流程使用的同一读取函数也已修复。

本版增加真正运行Inno脚本的账户回归测试，对照Windows当前令牌SID；本机构建完整安装包和Windows CI均执行此检查，不再只以C#核心/界面检查代替安装器验收。

## 下载与更新

请下载 **Click-Clean-3.0.3-win-x64-Setup.exe**，从托盘退出旧实例后运行完整安装包，保留设置、语言和历史；不必先卸载，也不要删除用户数据。尤其受保护系统整理组件尚未安装的用户，不要只做应用内更新。

保留3.0.2的手动原版三步、百分比模式不叠加系统低内存通知、普通权限登录启动、中英文和用户手动更新。界面与监测普通权限，系统步骤按需申请UAC。自动默认关闭，旧规则确认和用户选择保留。

x64便携包的三步需要已安装受保护组件；x86仅为64位Windows 11上的试验进程，不支持全系统三步、登录启动或应用内更新。源码包供开发者，`.nupkg`和`releases.win.json`是更新附件。

当前发行包未签名，不需关闭杀毒、绕过UAC或更改Windows账户。内存整理不保证释放量或提速，可能增加缺页及磁盘活动。回归方法及边界见 `docs/verification-3.0.3.md`。
