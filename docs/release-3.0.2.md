## 修复与变化

- 手动点击首页、托盘、整理岛直接执行原版三步，不再被“无需整理”、低占用、全屏或磁盘判断拦截。
- 自动占用模式按用户门槛执行三步，不再额外要求Windows发出低内存通知；修复关闭全屏避让仍被拦截。持续时间、冷却、防并发保留，自动默认关闭。
- 修复旧最高权限开机任务导致弹窗且无法启动：保留原开关和路径，迁移为普通权限启动；避免无限交接和开机重复弹窗。
- 保留3.0.1圆盘首页、中英文、主题及用户手动更新。

## 这次如何更新

**推荐下载 `Click-Clean-3.0.2-win-x64-Setup.exe`。** 从托盘正常退出旧版后运行完整安装包，完成系统组件安装和登录任务迁移，保留设置与语言。尤其此前只通过应用内更新到3.0的用户，需要完整安装包；普通更新不会从可写缓存提权补装组件。

手动三步和百分比自动三步按需请求UAC，界面与开机监测仍为普通权限。旧已开启的百分比自动规则需核对并确认一次；已选择Windows通知模式的用户保留原选择，可在设置中改为“占用百分比”。

便携包需要已安装受保护组件才能执行三步；x86包为64位Windows 11上的试验进程，不支持全系统三步、登录启动或应用内更新。源码包供开发者使用，`.nupkg`和`releases.win.json`为更新附件，不是安装程序。

执行成功不等于系统提速，可能产生缺页和磁盘活动；释放量允许为零或负值。当前包未签名，不需关闭杀毒或绕过UAC。测试范围见仓库 `docs/verification-3.0.2.md`。
