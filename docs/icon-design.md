# 图标设计 · 2.0.1

历史记录：此设计只用于 2.0.1。2.1.0 按用户要求恢复最初的蓝底白色波纹，当前 `App/Assets/ClickClean.png` 已替换；2.0.1 原资产仍可从对应 Git 标签查看。

新标识采用蓝紫圆角底色、冰白与青色的开放 C 丝带，以及开口处的四角星芒。C 呼应 Click-Clean，留白与流动造型呼应“给内存一点呼吸空间”，星芒表达整理后的清亮感。

设计使用内置 `imagegen` 工具辅助生成并迭代；保存的源资产为 `App/Assets/ClickClean.png`。不是 PCL、Apple 或其他产品的图标资源，也不宣称已经完成商标检索或获得注册商标保护。

提示词摘要：原创 Windows 应用图标；正视的蓝紫连续圆角方块；宽而流动的冰白至青色 C 丝带；一颗四角星；无文字、扫把、火箭、盾牌或芯片；透明留白；小尺寸高对比。迭代重点为减少外缘杂点、简化内部阴影并保持 C 的开放负空间。

`build-assets.ps1` 只使用内置源图离线缩放、封装 16、20、24、32、40、48、64、128、256 像素的 PNG 编码 ICO；不联网、不修改原图内容。可用 `-PreviewDirectory <目录>` 导出各尺寸预览。

主窗口标识与窗口 Icon 直接引用同一内嵌 PNG；可执行文件、托盘、Inno Setup 与 Velopack 使用同一 ICO。桌面迷你岛继续保持简洁状态标识，不添加装饰动画。

图标随项目分发，品牌使用规则仍以 `BRANDING.md` 为准。
