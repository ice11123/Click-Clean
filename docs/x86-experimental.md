# 32位试验便携包

这是运行于 Windows 11 x64（64位系统）上的 x86（32位进程）试验构建。Windows 11没有32位系统版本；它不表示支持Windows 10或32位Windows系统。常规用户请选择64位正式版。

解压完整目录，以普通权限运行ClickClean.exe。不要把它覆盖到已安装的64位目录。同一账户的两种版本共用单实例入口，请先从托盘正常退出当前版本再切换。设置与记录单独存放在%LOCALAPPDATA%/ClickCleanData-x86。

试验包不提供应用内更新、登录启动或高级系统组件；新版请从GitHub发行页手动下载。它不会读取正式x64更新通道，不能用正式更新包替换自身。日常整理采用相同的实际压力与有界后台准入规则。

已经修正32位窗口样式API调用，指针大小由运行时决定。界面与内存读数可以在本机WOW64下验证；高级组件仅支持x64，x86不从可写便携目录提权。不能以编译成功宣称没有bug或有固定性能收益。
