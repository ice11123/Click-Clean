# 2.5.0 桌面界面重构

以2026-10-12的桌面UI重构指导为依据，重做全部应用页面、导航与共享控件。保留WPF、原图标和已验证的内存/更新规则。

## 页面与层级

| Before | After | Why |
| --- | --- | --- |
| 首页入口与设置内诊断重复 | 概览、记录、诊断同级；设置独立入口 | 标题和功能归属一致 |
| 覆盖主导航的设置/历史页 | 固定外壳，切换内容区域 | 避免返回首页再进入另一目的地 |
| 首页展开器包含操作、提交量和自动说明 | 内存详情、自定义步骤、统一结果详情分别按需打开 | 每个入口有明确含义 |
| 5个挤在一起的设置标签 | 四组索引及明确返回路径 | 简化默认界面而不删除功能 |
| 自动表单所有参数同时出现 | 开关决定展开，门槛为共享条件，规则先保存 | 仅定时也可编辑门槛，关闭规则不校验无效输入 |
| 代码动态创建列表视觉元素 | XAML模板、可绑定集合、稳定行身份 | 主题一致，避免用户操作时反复重排 |

默认窗口560×600 DIP，最小440×540；工作区不足时适配工作区。默认成功状态首屏可见，最小窗口允许纵向滚动，无横向滚动。原生标题栏、原图标、原作者离子怪和三个不同图标外链保留。

浅色以浅灰/白为底、深蓝正文、红色主动作和少量金色；深色纯黑底、近黑控件、暗红主动作与白字。标题继承共享正文资源；数字使用等宽数字，不随数据更新做位置动画。主按钮、文本按钮、输入、选择器、开关、展开器、细进度条和滚动条统一样式。

## 行为与细节

整理、读数失败、自动规则和更新分别占独立位置。首页/托盘/岛共用执行门闩；默认原版三步不变，失败停止后续，取消等待当前调用返回。详情保留返回码、即时/3秒/30秒观测，零、负值和未知照实显示；观测记录写盘失败不伪装成系统步骤失败或一直观测中。

规则编辑只改变草稿；保存后生效，离开可保存/放弃/继续编辑。关闭的参数不接受键盘焦点、不强迫校验空值，保留原合法值。普通外观偏好即时保存，失败恢复真实值。诊断离页或隐藏停止进程扫描；进程可查看PID，不结束进程。

发现新版在概览提示，显示真实下载进度及取消，下载就绪仍需手动重启；检查/下载/校验失败保留重试。作者和外链由点击后使用系统浏览器打开。

桌面岛保持可视184×36 DIP、单击整理、过程与2秒成果。中性细边替代醒目金边，6 DIP灯按浅深色选择对应颜色，保留60/85分档与迟滞；55%自动门槛不改变灯色含义。呼吸2.8秒、透明度0.7～1，局部光仅表达状态，慢循环至多30帧。主窗隐藏但岛浮出仍正常显示；岛收起/隐藏、减少动画和高对比停止循环。

动效按emil-design-eng与animate：按压120ms、局部浮层180ms，沿用0.23/1/0.32/1缓出；频繁导航、键盘和数据更新立即响应。没有添加全页渐变、健康分数、虚构进度、巨大卡片或第三方UI框架。
