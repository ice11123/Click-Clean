## 整理不再反复弹 UAC

完整安装时授权一次。之后手动启动、开机自启和反复点击一键整理均无需重复管理员授权；首页、托盘和整理岛保持相同行为。

持久保存的是固定整理任务的授权，不是让整个界面长期以管理员运行。任务只能启动受保护目录中的原生组件；界面仅可读取和运行，不能修改高权限任务。组件按需启动、空闲退出，不增加高权限后台常驻服务，不降低UAC或关闭杀毒。

## 如何升级

**3.x用户这次需要下载 `Click-Clean-4.0.0-win-x64-Setup.exe`，从托盘退出旧版后覆盖安装。** 设置、语言、主题和历史保留。普通应用内更新不能代替这次管理员授权；同主版本的后续普通界面更新仍由用户手动下载和应用。

手动原版三步、百分比自动门槛、圆盘首页和中英文保持不变。自动整理与登录启动开关保持用户选择。便携版需要已安装4.0系统组件和授权任务；x86试验版仍不提供全系统三步、登录启动及应用内更新。

卸载正式开始时移除当前账户授权任务；取消卸载不提前破坏授权。授权任务缺失、被改动或权限不安全时明确提示修复安装，不回退逐次UAC。

当前发行包未签名；持续授权会让同账户其他程序也能请求固定整理操作，但不能运行任意管理员程序。整理可能增加缺页或磁盘活动，不保证提速或固定释放量。测试范围见 `docs/verification-4.0.0.md`。
