# Click-Clean 2.2.0 · UI 重设计

本次应用户要求由 `gpt-6-astra` 负责设计方向、配色和主窗口 XAML。Astra 完成主体布局后因额度限制中断；主代理保留该设计，补全全局控件样式、链接行为、原生标题栏和验收，而不是声称所有实现与验证均由 Astra 完成。

## 设计方向

蓝调状态主视觉 + 开放式三步流程 + 常驻作者页脚。默认主窗口 640×820 DIP，最低 440×560 DIP；主体滚动，作者与链接区不随内容滚走。保持原始图标，不改任务栏上方的薄胶囊。

视觉丰富来自真实信息层级、色面、字号、对齐和留白，不来自虚构曲线、健康评分、光晕或大量持续动画。物理内存使用率、可用量和提交量均沿用真实采样；数字使用稳定布局和等宽数字。

| Before | After | Why |
| --- | --- | --- |
| 平铺的小卡片与一行操作 | 蓝调状态主视觉、66 DIP 使用率数字、独立可用量、分隔统计 | 形成明确阅读顺序，突出实际状态 |
| 只有整理按钮 | 开放式 01/02/03 流程说明与清晰主动作 | 解释全系统操作，避免误认为只清软件自身 |
| 设置导航无明显选中态 | 与当前分区可见性绑定的分段选中态 | 无需猜测当前所在页面 |
| 系统默认输入框与混合边框 | 统一圆角、焦点边框、主题色光标和选择框 | 保持浅深色与输入可读性 |
| 大段历史文字 | 时间和状态标签、可用量变化、耗时、折叠返回码 | 区分主结果与诊断细节，不夸大释放收益 |
| 关于页只有仓库入口 | 常驻“原作者：离子怪”及三个不同矢量图标链接 | 署名与来源可发现，入口无需悬停才识别 |
| 深色客户区与默认标题栏 | 保留原生系统行为，使用 Windows 11 DWM 公开属性适配颜色 | 不自行重造标题栏或窗口按钮 |

## 主题与动效

浅色主背景 `#F3F6FB`、文字 `#172640`、强调 `#3567CF`；深色主背景 `#111925`、文字 `#ECF2FC`、强调 `#91B5FF`。新增 `AccentText` 处理强调按钮前景，浅色白字、深色 `#101A2F`，高对比取系统 HighlightText。其余主题沿用原有语义资源，不引入第二套主题配置。

主代理补齐显式标题样式的主题前景、圆角输入框、主题色光标、选择框与 10 DIP 的主题滚动条；弹出层关闭时恢复原焦点和原滚动位置。主题滚动条仍通过原生 ScrollBar/Track/Thumb 工作，没有新的输入钩子。

保留现有指针按压反馈与设置弹出动画，遵守减少动画；不增加装饰性循环动画，不动画化实时数字。底部岛的呼吸灯、2 秒成果、靠近浮出规则完全沿用 2.1.1。

原生标题栏使用微软公开 `DwmSetWindowAttribute` 的 Windows 11 属性，保留系统按钮和窗口行为；设置失败时原生窗口仍可运行。[微软 DWM 属性定义](https://learn.microsoft.com/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)

## 验收边界

主代理使用模拟内存数据检查界面，不为视觉验收执行真实整理。链接测试用注入打开器核对路由，不擅自打开多个浏览器页面；这不证明目标网站在所有网络环境中可访问。截图倍率不替代真实设备 DPI、屏幕阅读器及长期运行测试。审美仍需在实际桌面由用户体验确认。
