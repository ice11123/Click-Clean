# 2.5.0 验收记录

日期：2026-10-12。范围为桌面UI重构、展示/编排拆分和兼容性；不改变系统清理算法。

## 自动化与人工检查

核心49组测试通过，涵盖三步、7种组合、3种失败位置、取消、并发、观测、自动规则和新安装默认值。发行构建再次执行该套测试。

新版WPF诊断136项断言通过，零运行时绑定错误。覆盖默认浅色和岛开启、真实接口的模拟调用顺序、重复点击、取消等待、部分失败、观测写入失败、低压力自动跳过/全屏/磁盘避让、系统压力模式、独立诊断与停采样、草稿的保存/放弃/继续编辑、仅定时共享门槛、关闭后无效输入、外链图标、详情和焦点、手动更新、浅深色实际标题与按钮颜色、默认首屏、窄窗口、岛结果2秒与减少动画。断言数不是独立场景数。

检查实际渲染的浅深色首页、设置索引、外观、展开自动规则、诊断、结果面板与岛。首轮发现的默认页面24 DIP溢出已调整；人工检查发现的深色标题资源继承遗漏已修正并新增颜色断言。测试使用隔离配置、注入系统/更新/进程模拟，未运行用户安装或修改其配置。

100%、125%、150%、175%、200%是离屏渲染倍率，不是系统显示缩放实测；窄窗口单独改变实际窗口尺寸验证。高对比、Windows文本放大、多显示器跨屏、特殊/自动隐藏任务栏和本机安装覆盖仍需对应环境验收，不宣称已全部实测。

更新包沿用现有23项传输、服务与恢复校验，最终发行包会再次执行。重启替换使用模拟接口/文件源，不改用户安装；包大小、SHA-256、就绪前及应用前校验保持原逻辑。
