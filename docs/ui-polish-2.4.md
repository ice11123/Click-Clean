# 2.4.0界面与动效精修

按emil-design-eng、animate技能：常见交互轻量反馈，数据布局保持固定，键盘操作即时响应。保留红/金/深蓝与黑/暗红/白、最初图标和任务栏中央薄岛。

| Before | After | Why |
| --- | --- | --- |
| 560×620、结果较弱、中下部留白偏大 | 560×580、收紧分隔间距、复测结果17字号、诊断入口置于顶部 | 集中主要操作与结果，避免增加功能后堆叠大卡片 |
| 主结果与岛成果使用即时变化 | 优先3秒复测，30秒后台观测作为小字补充，细节折叠 | 更容易辨认持续性，不把瞬间下降等同提速 |
| 新版本提示占用较多高度 | 紧凑单行，长状态悬停可读全文，下载时显示进度及取消 | 让检查/下载/手动重启职责清楚 |
| 呼吸灯跨分界立即换色 | 2个百分点迟滞、180毫秒颜色过渡，减少动画/高对比/收起时直接最终色 | 防止边界闪动，数字与自动阈值不被平滑改变 |
| 鼠标远离也每150毫秒检查前台窗口 | 远离每500毫秒只读鼠标，接近恢复150毫秒与全屏检查 | 降低后台轮询代价，维持接近时的响应 |
| 呼吸和整理背景使用默认持续帧率 | 两种慢速循环限制为30帧，短时按压和浮出保留原反馈 | 降低透明窗口持续合成代价 |
| 进程诊断可能成为常驻负担 | 只在可见诊断页每5秒后台读数，关闭页面停止 | 使诊断成本与用户操作对应 |

底部岛不改变尺寸，不增加额外按钮。原150毫秒浮出/收回、120毫秒0.97按压和整理态局部渐变继续使用既有动效。换色用途是状态指示，使用WPF原生ColorAnimation，180毫秒；没有引入动效库。实时数字、排行榜排序和键盘导航不添加装饰动画。
