# 3.0.2 验证

日期：2026-10-17。本版恢复用户明确要求的手动三步，修复百分比自动模式的重复压力门槛，以及旧最高权限登录任务与普通权限界面的冲突。

## 已完成

- 核心65组测试通过：手动固定2/3/4、百分比到门槛即执行（包括85%且通知未知）、系统通知后台策略、顺序和七种高级组合、并发、失败和取消，以及旧配置确认和语言保留。
- 隔离WPF界面188项检查通过：低占用/全屏/磁盘忙碌/通知未知均不阻止手动点击；重复点击仍受门闩保护。百分比模式55%和85%均发送2/3/4，关闭全屏避让后不再被硬编码拦截。覆盖浅深色、English、圆盘、键盘、侧栏、整理岛及手动更新。系统调用为模拟，不代表实机收益。
- 本机真实登录任务原为HighestAvailable，动作指向已安装3.0.1并带`--tray`。迁移后COM读数为Limited、仍Enabled；启动动作和登录触发器保持不变，没有删除其他任务。验收先备份任务XML。
- 管理员探针通过当前账户InteractiveToken创建无触发器的普通权限交接任务。子进程核实Admin=false，删除交接任务后仍存活并输出结果；最终无交接任务残留。整理命令发送数为0。
- 首次探针在读取XML时错误地要求显式RunLevel节点；Windows省略默认LeastPrivilege节点导致探针失败，但任务已降低权限。修正探针读取默认值后复验通过，不将第一次探针失败冒充迁移失败。

## 限制与发布门禁

没有重启本机验证完整登录周期，没有执行本机全系统三步，也没有本版应用/游戏性能对照实验；不能宣称释放固定容量或提高帧率。强制手动三步可能增加缺页、缓存重载和刷盘活动。

本机受保护系统组件尚未安装，因此必须使用本版完整安装包补装；普通应用内更新不会提权写入Program Files。x86试验版明确不支持全系统三步，不从可写便携路径提权。

发布需通过同提交Windows CI、Native AOT来源及协议自测、隔离runner组件认证、更新传输测试，并逐项核对公开附件SHA-256。安装包仍未签名。尚未实测的安装覆盖、卸载和真实DPI环境不冒充已经验收。
