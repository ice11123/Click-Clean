# 底部整理岛 · 2.1.0

入口固定在主屏工作区底部中央，位于任务栏上方。可见胶囊为 184×36 DIP；216×72 DIP 的透明窗口仅用于提供上浮空间，不是可见面板。没有拖动、展开菜单、打开窗口或收起按钮；整枚胶囊的唯一动作是一次三步整理。

鼠标进入工作区底部中央 18 DIP 高的触发区时浮出。浮出后扩大保持区，鼠标离开约 220 毫秒后收回。悬停不会整理，点击后立即置忙；当前调用不中断，重复点击不并发执行。状态只保留内存使用率、整理中或简短结果。

按 `emil-design-eng` 与 `animate` 原则，仅使用原生 WPF 的变换和透明度动画；浮出/收回 150 毫秒，按压缩放到 0.97、120 毫秒，缓出曲线 `(0.23, 1, 0.32, 1)`。中断时从当前呈现值继续，不弹跳，不做持续呼吸动画。减少动画时禁用位移与按压动画；键盘操作不播放按压动画。

鼠标位置采用低频 `GetCursorPos` 读取，不安装全局鼠标或键盘钩子，不注入 Explorer。收起时透明且不命中鼠标；点击不激活窗口。检测主屏上的非 Shell、无标题栏且覆盖整屏的前景窗口时收回并取消置顶。此检测是窗口几何判断，不保证识别所有特殊全屏实现。

显示、工作区或 DPI 消息变化时重新停靠。不支持多屏拖动定位。任务栏自动隐藏、特殊第三方任务栏与不同显示缩放仍需真实环境补充验收。主窗口保留设置、更新和历史，托盘仍可退出软件。

用户设置升级到 schema 2；第一次升级启用底部入口，后续保存的关闭选择不再被重新开启。旧拖动位置和置顶属性不再使用，其他设置、历史和自动清理配置保留。图标恢复自最初清栖的自有波纹资源，不再使用 2.0.1 的 AI 辅助 C 图标。
