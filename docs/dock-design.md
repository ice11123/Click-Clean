# 底部整理岛 · 2.3.1

入口固定在主屏工作区底部中央，位于任务栏上方。可见胶囊为 184×36 DIP；216×72 DIP 的透明窗口仅提供上浮空间。没有附加按钮或菜单。点击通过共用入口执行原版三步，不受占用阈值限制；未知快照安全停止。55%默认门槛仅用于自动整理，不影响岛的手动点击。

鼠标进入工作区底部中央 18 DIP 高的触发区时浮出。浮出后扩大保持区，鼠标离开约 220 毫秒后收回。悬停不会整理，点击后立即置忙；当前调用不中断，重复点击不并发执行。状态只保留内存使用率、整理中或简短结果。

按 `emil-design-eng` 与 `animate` 原则，仅使用原生 WPF 的变换和透明度动画；浮出/收回 150 毫秒，按压缩放到 0.97、120 毫秒，缓出曲线 `(0.23, 1, 0.32, 1)`。中断时从当前呈现值继续，不弹跳。减少动画时禁用位移与按压动画；键盘操作不播放按压动画。

状态由独立模型驱动，不根据中文字符串猜测业务阶段。整理中显示当前步骤及序号，不编造百分比；完成后用单调时钟保留成果 2 秒，独立于 1 秒或 10 秒内存采样。采样更新不会重置期限，更新就绪提示留在主窗口。结果中的正值、负值、零和未知均如实显示；重启不会重新展示旧成果。若岛收起，两秒期限仍继续，重新浮出时显示当前阶段，不回放过期成果。鼠标离开仍按原规则收回，不强制常驻。

数字列固定宽度和等宽数字，不随数字跳动。灯保持 5 DIP，仅改变透明度：原生线性动画在 0.4～1 间往返，每半周期 1200 毫秒，不用额外模糊或光晕。低于 60% 为绿、60%～85% 为琥珀、85% 及以上为珊瑚红；这是 UI 分档，与自动清理阈值独立，也不表示硬件异常。未知读数显示“内存 —”和静态灰灯。颜色随采样变化，数值刷新不重启呼吸周期；整理期间仍依据实际内存占用变色。

浮出时立即读一次状态，之后每秒采样；隐藏主窗口且岛收起时降为 10 秒。收起、全屏抑制、禁用入口、减少动画、系统关闭动画或退出时移除呼吸时钟；隐藏时不运行成果展示计时器，重新浮出时按单调期限重新判断。

鼠标位置采用低频 `GetCursorPos` 读取，不安装全局鼠标或键盘钩子，不注入 Explorer。收起时透明且不命中鼠标；点击不激活窗口。检测主屏上的非 Shell、无标题栏且覆盖整屏的前景窗口时收回并取消置顶。此检测是窗口几何判断，不保证识别所有特殊全屏实现。

2.3 起背景、文字、边框和局部渐变跟随应用浅/深/系统主题。浮出时渐变透明度 0→0.16、180 ms，完成移除时钟；仅整理/复测期间局部横移 -10→10 DIP、1200 ms 单程往返，透明度 0.24。数字不移动。收起、禁用、减少动画、系统关闭动画、高对比及释放窗口均移除背景时钟；高对比不显示渐变。详情见 [Astra 审计](ui-audit-2.3-astra.md)。

显示、工作区或 DPI 消息变化时重新停靠。不支持多屏拖动定位。任务栏自动隐藏、特殊第三方任务栏与不同显示缩放仍需真实环境补充验收。主窗口保留设置、更新和历史，托盘仍可退出软件。

用户设置升级到 schema 2；第一次升级启用底部入口，后续保存的关闭选择不再被重新开启。旧拖动位置和置顶属性不再使用，其他设置、历史和自动清理配置保留。图标恢复自最初清栖的自有波纹资源，不再使用 2.0.1 的 AI 辅助 C 图标。
