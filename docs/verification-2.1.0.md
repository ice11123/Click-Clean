# 2.1.0 底部整理岛验证

日期：2026-10-02。

- 原始自有波纹图标的 256 像素 PNG 从旧 ICO 中直接取出，重新离线封装多尺寸 ICO；未采用 2.0.1 的 C 图标。
- 22 组核心测试通过，包括原有七种整理组合、三个失败位置，以及靠近/离开迟滞、全屏抑制、时钟异常与设置 schema 迁移。
- 本机 WPF 诊断通过 75 项断言：固定底部中央、36 DIP 可见高度、唯一点击按钮、悬停不整理、拒绝重复点击、隐藏时命中测试返回透明、不激活鼠标消息、全屏状态收回、位置重算、150 毫秒位移及中途反向不跳位。
- 浅色/深色主窗、设置、历史、小窗口及 100%～200% 离屏倍率截图已生成；底部岛截图已经人工检查。倍率截图不等于真实 Windows 缩放验收。
- 主窗口隐藏、底部岛开启并实际监听鼠标的 30 秒测量：整机 CPU 约 0.0098%，工作集约 140 MiB、私有内存约 88 MiB。该诊断过程包含大量截图与模拟状态，不等同于长期正式运行的基准。
- 旧清栖在本机经其卸载程序移除，应用注册、程序文件和当前账户的启动任务均不存在；数据保留，不需重启。

窗口交互测试使用模拟整理，不调用系统内存整理接口。全屏分支采用注入的状态验证，真实游戏、第三方任务栏、任务栏自动隐藏及多屏/混合 DPI 场景尚未完全实测。主屏几何检测的局限见 `dock-design.md`。

本机交付辅助命令 `--update-installed` 只支持当前用户已注册的默认 Click-Clean 安装；使用已校验的本地 Velopack 包，正常退出旧实例后调用原生更新器。不强杀正在整理的实例，不关闭 UAC，不运行安装向导。更新有三分钟超时，失败时停止交付，不强行中断系统调用。

程序仍未签名，不承诺杀毒软件零误报。清理步骤、计划任务权限和自动清理逻辑没有改动。
